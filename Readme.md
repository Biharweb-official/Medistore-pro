# MediStore Pro - Medical Store Management System

A modern, lightweight web-based pharmacy management system designed to handle inventory, track medicine expiry dates, and manage POS billing seamlessly.

## 🚀 Features
- **Multi-User Authentication**: Secure store registration and login.
- **Smart Inventory**: Add, search, and manage medicines with real-time stock levels.
- **Expiry Tracking**: Color-coded alerts for expired and near-expiry medicines.
- **POS & Billing**: Generate professional invoices with automatic GST calculation and print support.
- **Sales History**: Track daily and total revenue records.

## 🛠️ How to Use
1. Clone or download this repository.
2. Open the `index.html` file in any modern web browser.
3. Register your store and start managing your medical inventory!
